# ⚽ Football Player Performance Indicator

An advanced football analytics web application developed to analyze player performance using data analysis and machine learning. The application provides player profiles, player comparisons, player replacement recommendations, Expected Goals (xG) prediction, and player position prediction through an interactive web interface.

---

## 🌟 Features

- **Dashboard:** Explore football player statistics and performance insights.
- **Player Profile:** View detailed statistics and performance information for individual players.
- **Head-to-Head Comparison:** Compare two players using important performance metrics.
- **Player Replacement:** Identify potential replacement players based on statistical similarity.
- **xG Prediction:** Predict Expected Goals (xG) using a trained machine learning regression model.
- **Position Prediction:** Predict a player's playing position using a classification model.
- **Interactive UI:** Football World Cup themed interface with interactive visual elements.

---

## 📊 Dataset

The project uses football player statistics stored in:

`world_cup_player_stats.csv`

- Statistical comparison
- xG prediction
- Position prediction
- Player similarity and replacement analysis

## 🤖 Machine Learning Models

### Expected Goals (xG) Prediction

A regression model is used to predict the Expected Goals (xG) value based on player performance statistics.

**Model file:**

`xg_model_bundle.pkl`

### Position Prediction

A classification model is used to predict the playing position of a football player.

**Model files:**

`position_classifier.pkl`

`knn_position_bundle.pkl`

### Player Replacement Recommendation

Player replacement recommendations are generated by comparing player performance characteristics and statistical similarity.

## 🚀 Getting Started Locally

Follow these steps to run the project on your local machine.

### 1. Clone the Repository
git clone https://github.com/meenakshimeenuzz21/Football-Player-Performance-Indicator.git
cd Football-Player-Performance-Indicator


### 2. Create a Virtual Environment
python -m venv venv

### 3. Activate the Virtual Environment
Windows:
venv\Scripts\activate
macOS/Linux:
source venv/bin/activate

### 4. Install Dependencies
pip install -r requirements.txt

### 5. Run the Application
python app.py

### 6. Open in Browser
Navigate to:
http://127.0.0.1:5000
